## Founder Feedback Recorded for M29

### Product Experience Refresh

The current UI is stable and professional but reads more like an academic research portal or enterprise internal dashboard than a modern AI quantitative product.

M29 should move toward an **AI Quant Decision Workspace** through:

- a modern neutral palette;
- clean sans-serif typography;
- stronger product identity;
- improved visual hierarchy;
- more usable forms and tables;
- purposeful data visualization; and
- a Founder Dashboard with workflow-oriented next actions.

### Multilingual Product Foundation

The product must preserve English as the default language and add complete Simplified Chinese (`zh-CN`) support.

The multilingual foundation must:

- provide an explicit language switcher;
- localize navigation, product copy, forms, loading/empty/error states, confirmations, and stable frontend error explanations;
- preserve route paths and query parameters while switching languages;
- preserve raw strategy names, IDs, UUIDs, API values, schema versions, timestamps, artifact content, and transport payloads without translation;
- avoid adding locale prefixes unless a later product requirement justifies them; and
- precede the broad visual refresh so both English and Chinese layouts shape the design system.
