# Comparisons

Comparisons places a small, explicit set of completed paper results side by side
without ranking them.

## Create a Comparison

1. Open **Comparisons**.
2. Review the succeeded paper jobs shown as candidates.
3. Select two to four distinct jobs whose result is available.
4. Choose **Compare selected results**.

The applied comparison preserves its explicit order. Results are loaded
independently, so successful results remain visible if another selected result
fails. Retry an individual failed result or use **Refresh comparison** to reload
the whole set once.

## What Is Compared

The workspace juxtaposes:

- run identity and result provenance;
- starting and ending account-cash snapshots;
- session timestamps, cash values, and order/fill counts;
- the separate backend result audit; and
- ordered positions and backend-provided position changes.

Open the linked Portfolio Record for a selected job to inspect its complete
orders and fills.

## Make a Human Comparison

The page does not calculate cross-run cash or quantity differences, align
symbols or trades, reconcile audits, compute return or risk, score results, or
identify a winner. It also does not create a comparison decision artifact.

Use the displayed facts to write your own conclusion. Record which runs were
compared, why they were comparable, what evidence was missing, and why the
observed differences matter. A visually larger cash value is not by itself a
profitability or suitability conclusion.
