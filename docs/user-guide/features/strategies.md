# Strategies

The Strategies area is the read-only catalog of strategy definitions available
to the Founder Workspace.

## Review a Strategy

1. Open **Strategies and Research**.
2. Select **Strategies**.
3. Choose **Inspect** for the definition you want to review.
4. Confirm the exact strategy name, display name, and description.
5. Review each parameter's value type, required status, and default value.

Use the exact strategy name when matching the definition to saved research. The
research list is separate and is not automatically filtered to the strategy you
opened.

## How to Interpret the Page

Parameter metadata describes the strategy contract; it is not an editable
configuration form. A default value is not automatically appropriate for every
dataset, symbol, or review objective.

The catalog does not show performance and does not indicate that one strategy
is safer, better, or more profitable than another. Continue to
[Research](research.md) for saved evidence.

## What This Area Does Not Do

It does not edit parameters, execute research, start a paper run, score
strategies, or provide an AI recommendation.
